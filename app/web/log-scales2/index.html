Log Scales 2

All demos

Nine values in each power of ten from a millionth to a hundred million. On an ordinary scale all but the top power of ten crowd along the bottom.

The same values on a logarithmic scale, with a tick at each power of ten: every power of ten gets the same height.

The same values on a logarithmic scale whose ticks are powers of two.

Values from -100 to 100 through zero. A logarithmic scale has no place for zero or negative numbers, so those samples are left out and the line breaks.

Two values fourteen powers of ten either side of one. There are too many powers to label, so the axis labels only every few.

The same on a base-2 scale: the axis labels only some of the powers of two.

Three values from 100 to 1000, with the axis range set by hand in this demo to 100 to 1000. uPlot's original adds a series with no values to check that the range ignores it; this page has no such series.

Two values of order 1e-16 and 1e-13, to show the axis still labels sensibly at such tiny sizes.

Four values an hour apart on a logarithmic scale, drawn twice: above as they are, below on an inverted scale that labels each value as its negative, so the largest is lowest.
